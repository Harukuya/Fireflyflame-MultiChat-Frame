# 添加自己的表情包

框架不包含表情图片，只保留目录示例。

Runtime 的实际表情目录是 `<data_root>/stickers/<中文类别>/`，可从仪表盘「表情包」卡片查看绝对路径。不要放在 SDK 或框架安装目录，运行数据应与源码分开。

```text
stickers/
  开心/
    表情.png
  疑问/
    表情.webp
```

支持 JPG、JPEG、PNG、GIF、WebP。新建一层中文文件夹后自动识别，文件夹名成为角色可以选择的表情类别；空目录不给模型。框架原有的英文类别别名继续可用，中文目录与同名既有类别合并显示。

图片发送由 Transport.send_image 实现；平台不支持图片时返回 False。自行添加的图片需要接入者确认其来源与使用权限。
